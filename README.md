# FilmFeed Games 4K (FitGirl Repacks Web Portal)

A high-performance modern web application for browsing, searching, and requesting PC game repacks directly from FitGirl Repacks with multi-mirror RAR multipart download links and WhatsApp Auto-Bot integration.

## Features
- **Fast WordPress REST API Scraping**: Fetches the latest game releases, repack sizes, genres, and multipart archives in real time.
- **Multi-Part Download Resolution**: Extracts FuckingFast, DataNodes, and FileKeeper RAR parts (~500MB each).
- **3-Step Ad Verification Flow**: Built-in 3-step countdown security verification with Adsterra banner and popunder integration.
- **WhatsApp Bot Integration**: Generates verified download tokens (`#GF-XXXXXX`) and 1-click WhatsApp request links for automated sequential Baileys document delivery.
- **Responsive Dark Cyberpunk UI**: Built with Next.js 14 App Router, Tailwind CSS, and Lucide React.

## Deployment to Vercel
1. Push this repository to GitHub.
2. Import project into [Vercel](https://vercel.com).
3. Framework Preset: **Next.js**.
4. Root Directory: `./`.
5. Click **Deploy**.
